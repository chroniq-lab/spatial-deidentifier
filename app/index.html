Spatial De-identifier — Config Builder

Builds config.json for deidentify.py and runs it locally. Files never leave this computer.

1. Load a sample of each file (optional, CSV only)

Loaded files are uploaded to the local app when you click Run. CSV files also fill the column dropdowns from the first ~2,000 rows; for Excel/Parquet, type the column names manually.

3. ID and state columns

County state "(derive from FIPS)" uses the first 2 digits of the FIPS code. IDs are zero-padded to 5 characters.

4. Variables

County variables
ColumnTypeBinningSample
ZIP variables
ColumnTypeBinningSample

Types: continuous (bins merged until they pass, ≥4 kept), ordinal (adjacent levels merged, ≥4 kept), binary (never merged), auto (decided by the script). If no variables are selected on a side, the script uses every numeric non-ID column with type auto.
Binning (continuous only): default uses the percentiles above; percentiles sets this variable's own percentiles (0–100); cutoffs sets break-points in the variable's own units (e.g. 40000, 60000, 80000; each bin includes its lower bound). These are starting points that are still merged if a bin fails. Tick fixed to keep them exactly: the variable is then never merged, and is excluded if any bin fails.
